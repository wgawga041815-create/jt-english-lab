# JT English Lab · 俊通达外贸英语

围绕俊通达电子的充电器 / 数据线 / OEM 外贸业务设计的练习站。

## 内容
- 1000 个高频商务词：基础商务、产品、外贸流程、客户展会、出差日常、办公室、认证质量、物流单证、谈判价格、电商营销
- 16 个基础语法点，每个 6 道题
- 45 组听力：初级、中级、高级，覆盖询盘、样品、报价、付款、验厂、出货、投诉、索赔、代理、接机、酒店、点餐、审核、高层会议等
- 54 个口语任务：公司、产品、报价、压价、延期、展会、跟进、接机、酒店、点餐、验厂、投诉、索赔、代理、审核、年度复盘、完整电话
- 分级练习：初级 / 中级 / 高级，可按当天课程挑

## 使用
直接用浏览器打开 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8788
```

建议 Chrome / Edge。发音使用浏览器语音合成；录音需要麦克风权限。
学习进度保存在浏览器 localStorage，不会上传。
